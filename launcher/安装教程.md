# 蓝色大肥鱼 · 安装教程

> 目标：在一台 **Windows 电脑** 上，把这只 QQ 鲸鱼娘跑起来。
> 你只需要准备一个 **QQ 小号**、一把 **DeepSeek API Key**；想要语音/唱歌再加一张 **NVIDIA 显卡**。

---

## 0. 先看清楚：这东西有多大

| 项目 | 要求 | 说明 |
|---|---|---|
| 系统 | Windows 10/11 64 位 | QQ 客户端和计划任务只支持 Windows |
| 内存 | 8 GB 起，16 GB 舒服 | 语音/唱歌会吃 4~6 GB |
| 硬盘 | **至少 30 GB 空闲** | AstrBot 1G + SnowLuma 0.5G + 模型 12~20G |
| 显卡 | 可选：NVIDIA 6 GB 显存以上 | **没有显卡也能用**：能聊天、画画、点歌（云端 TTS 不需要）；但"她自己的声音"和"唱歌"要显卡 |
| 网络 | 能上外网 | DeepSeek / 网易云 / 抖音都要 |

> ⚠️ **没有显卡的机器**功能表：
> ✅ 文字聊天、长期记忆、表情包、画画、点歌、课表、提醒、群管理通知
> ❌ 用她的音色说话（TTS）、唱歌、本地语音识别（STT）

---

## 1. 准备三样东西

### 1.1 QQ 小号（必须）

- 用**小号**，别用主号——机器人要挂在 QQ 上，主号有一定风险（风控、冻结）
- 小号要能正常登录（扫码或密码都行）

### 1.2 DeepSeek API Key（必须）

1. 打开 https://platform.deepseek.com/api_keys
2. 登录 → 「创建 API Key」→ 复制 `sk-` 开头那串
3. 按量计费，日常聊天一小时通常几毛钱

### 1.3 网易云 Cookie（可选，想要点歌/唱歌才需要）

1. 电脑浏览器登录 https://music.163.com
2. F12 → Application → Cookies → 复制 `MUSIC_U`（和 `__csrf`）的值
3. 把它们按 `MUSIC_U=xxxx; __csrf=yyyy` 的格式粘进控制台（脚本会自动转成插件要的格式）

> 用**自己的会员号**才能下 320k；不填也能跑，只是点歌/唱歌会提示拿不到。

## 2. 安装基础环境

### 2.1 装 Python（3.10+）

https://www.python.org/downloads/ → 下载 → 安装时**勾选 Add python.exe to PATH**。

验证：Win+R 输入 `cmd`，敲 `python --version`，能看到 3.10 以上就行。

### 2.2 装 Node.js（18 或 20 LTS）

https://nodejs.org/ → 选 LTS → 一路下一步。
验证：`node -v`。

### 2.3 放好 SnowLuma

SnowLuma 是 QQ ↔ OneBot 的桥（QQ 客户端必须开着，由它接管）。

1. 从它的发布页下载 SnowLuma（Windows 包）
2. 解压，把里面的 `app` 文件夹放到：
   ```
   安装目录\
     SnowLuma\
       app\        ← 这里有 index.mjs
   ```

### 2.4 放好 AstrBot

控制台里点 **① 环境自检**，如果提示 `AstrBot 目录: 缺少`，用安装脚本装：

```powershell
# 在 BlueFishStudio\scripts 目录里，右键 install.ps1 → 用 PowerShell 运行
# 或者：
powershell -ExecutionPolicy Bypass -File install.ps1
```

它会：装 `uv` → `uv tool install astrbot` → 建目录 → 建桌面快捷方式。

### 2.5（可选）放好语音模型

想要"她自己的声音"和"唱歌"，需要这三样（体积大，需自行下载）：

| 组件 | 用途 | 放置位置 |
|---|---|---|
| **GPT-SoVITS**（含模型 + 参考音） | 文字转语音 | `安装目录\Models\GPT-SoVITS\` |
| **Seed-VC**（F0 44k 歌声模型） | 唱歌换声 | `安装目录\Models\seed-vc\` |
| Demucs / Whisper 模型缓存 | 分离人声 / 语音识别 | `D:\torch-cache\`、`D:\hf-cache\`（脚本会读这两个路径） |

> 没有这些：控制台的"语音合成 TTS / 语音识别 STT"端口一直是灰的，但**聊天照常**。

## 3. 第一次配置（5 分钟）

1. 双击桌面 **蓝色大肥鱼**（或 `BlueFishStudio\启动.vbs`）
2. 切到 **① 环境自检** → 点「重新检查」
   - ✅ 绿色：没问题
   - ⚠️ 黄色：能用但功能少
   - ❌ 红色：按提示先解决（通常是缺目录/没填 Key）
3. 切到 **② 账号与认证**，填：
   - QQ 小号（例如 `123456789`）
   - 登录方式：**手机扫码**（推荐）
   - DeepSeek Key
   - 网易云 Cookie（可选）
   - 功能开关
4. 点 **「保存并写入配置」**——它会把你的信息写进 AstrBot 和 SnowLuma 的配置里（只写本机，不上传）
5. 切到 **③ 启动 / 状态**，点 **「▶ 一键启动」**
6. 打开 **SnowLuma 页面**（按钮就在旁边）→ 用手机 QQ 扫码登录小号
7. 扫码成功后回到控制台，看到 **OneBot 端口 3000 = 运行中** 就成了

## 4. 验证

在小号的朋友里找一个号（或者用你自己的号加它），发一句：

> 在吗

正常应该 1~3 秒内回你一句。控制台 ③ 页面会显示 4 个服务在线。

## 5. 常见问题

**Q：点「一键启动」后 OneBot 端口一直是灰的**
A：QQ 客户端没开 / 没登录 / SnowLuma 没起来。依次检查：
1. 任务栏有没有 QQ
2. 控制台 ④ 日志里有没有 `SnowLuma starting`
3. `安装目录\SnowLuma\app\logs\` 里最新的日志

**Q：她只回文字，不语音**
A：没装 GPT-SoVITS，或装了但没配参考音。这是可选项，不影响聊天。

**Q：点歌提示"拿不到"**
A：网易云 Cookie 没填/过期，或者这首歌需要买专辑（周杰伦原版多数是这样，属正常）。

**Q：能给别人用吗？**
A：这台机器就是"她的大脑"，别人加的 QQ 号只要加到小号的好友里就能和她聊。**但注意**：所有对话都跑在你这台机器上。

**Q：会和 QQ 官方冲突吗？**
A：SnowLuma 是第三方客户端桥，属于灰色地带。**用小号、别刷屏、别发违规内容**，这是降低风险的基本操作。

---

## 6. 卸载

1. 控制台 ③ 点「■ 停止」
2. 任务计划里删掉 `bot-stack-start` / 相关任务
3. 删除安装目录 + 桌面快捷方式
4. 卸载 Python / Node / QQ（按需）

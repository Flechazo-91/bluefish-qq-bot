# 蓝色大肥鱼 · 使用教程

> 装好之后怎么用。她不只是个聊天机器人。

---

## 一、怎么叫她

| 场景 | 怎么做 |
|---|---|
| 私聊 | 直接发消息，不用 @ |
| 群聊 | **@她**，或者用 `/` 开头（例如 `/点歌 起风了`） |
| 她睡着了 | 默认 00:00–08:00 会回「大肥鱼睡觉中，等他起了就回复你」并记账，早上补回 |

想换唤醒词：AstrBot 管理页 → 配置 → `wake_prefix`（默认是 `/`）。

---

## 二、日常聊天

- 有人设、有长期记忆（记得你之前说过的事、记得群里的梗）
- **群聊会看上下文**：别人聊了几句再 @她，她知道前面在说什么
- 会自己配表情包（按语境挑，不是乱发）
- 私聊有「正在输入」和 0.8~4 秒的真人延迟

---

## 三、唱歌 🎤（要显卡）

| 说法 | 效果 |
|---|---|
| `唱一首 起风了` | 搜歌 → 取 15 秒副歌 → 分离人声 → 换成她的音色唱 |
| `来给唱首爱错` | 同上（群里的口语说法也认） |
| `你给小王唱一首吧` | 没点名就随机挑一首 |

- 大概 **35~60 秒**出结果，她会先说一句「在准备，别急」
- 念白/朗读版会自动跳过，换下一个版本
- 歌手不对、翻唱、伴奏、README 类都会降权

---

## 四、点歌 🎵

```
点歌 起风了
```

- 放原曲的 40 秒副歌（不是她唱）
- 配额：**每人每天 8 首、全局 40 首**
- 会员曲没版权会自动换版本，并注明「原版是会员曲」

---

## 五、画画 🎨

```
画 一只猫在打游戏
文生图 星空下的鲸鱼
帮我画 一个赛博朋克街道
```

- 引擎是通义万相（云端），约 ¥0.005/张
- 等 5~15 秒出图

---

## 六、语音与视频

- **发语音**给她：本地 Whisper 转文字再回答（要装 STT）
- **私聊发短视频**（≤3 分钟）：抽九宫格关键帧理解画面 + 音轨转写，能聊视频内容

---

## 七、课表 📅

| 问法 | 她会答 |
|---|---|
| `明天课表` | 明天的课（按真实日期算，不会串周） |
| `本周课表` | 本周概览 |
| `下下周` | 已录入的周次都能算 |
| `下一节课` | 最近的一节 + 几点开始 |

课表数据在 `AstrBot\timetable.json`，自己去填（格式见文件里的示例）。  
早报 7:30 自动发；课前 15 分钟提醒；每周日 20:00 提醒补下周课表。

## 九、抖音（可选，默认关）

开了之后她会：

- 每天 3 次（12:30 / 18:30 / 21:30）自己去刷推荐流 20 分钟，自动跳过直播、按配额点赞
- 每两天 19:30 自动发一条作品（图文或视频）

⚠️ 需要你**先在自己的电脑上登录一次抖音**（用她自带的 Edge 窗口扫码），登录状态会存住。首次使用请先看 `AstrBot\douyin\` 目录里的说明。

## 十、私信/群通知（给别的程序用）

任何脚本干完活都能让她发个 QQ：

```cmd
D:/AstrBot\notify-qq.cmd "任务完成：切片 12 条已入库"
```

## 十一、控制台怎么用

| 页签 | 用途 |
|---|---|
| ① 环境自检 | 检查系统/依赖/端口/配置，红色必须先解决 |
| ② 账号与认证 | 填 QQ、Key、Cookie；保存后自动写进服务配置 |
| ③ 启动 / 状态 | 一键启停、看 6 个服务端口、打开管理页 |
| ④ 日志 | 看最近 200 行日志，出问题先看这里 |

---

## 十二、出问题了怎么查

| 症状 | 先看 |
|---|---|
| 不回消息 | ③ 里 OneBot 端口在不在；QQ 有没有掉线 |
| 语音发不出 | ④ 日志搜 `TTS failed`；9880 端口在不在 |
| 唱歌失败 | ④ 日志搜 `[sing]`，会写清是「念白跳过」还是「变声失败」 |
| 表情包不发 | AstrBot 管理页 → 插件 → meme_manager 里看 pack 是否启用 |
| 整体卡住 | ③ 点「■ 停止」再「▶ 一键启动」 |

---

## 十三、几条风险提醒

1. **必须用小号**，别用主号；机器人挂了 QQ 客户端
2. **Cookie / API Key 只存在本机**，别截图发出去
3. 自动化操作（抖音/群发）**别密、别刷**，平台风控会盯
4. 她发的 AI 内容（抖音作品）建议标「AI 生成」，避免被下架

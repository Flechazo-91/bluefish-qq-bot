## 四、唱歌 🎤

**完整链路**：搜歌 → 取 15 秒副歌 → Demucs 分离人声/伴奏 → Seed-VC（F0 44k 歌声模型）把原唱人声换成她的音色 → 混音 → 发语音

| 能力 | 说明 |
|---|---|
| 触发 | 「唱一首 起风了」「来给唱首爱错」「你给小王唱一首歌吧」都认（先剥垫词，句首不是"唱"也能识别） |
| 群里唱 | 支持，@她 说就行 |
| 智能跳过 | 遇到朗读/念白版自动换下一个版本（用音符密度判断：中位音符 < 0.22s 且音符数 > 35 → 判定念白） |
| 候选筛选 | 一次拿 12 个候选依次试，歌手对不上重罚，翻唱/伴奏/朗读版进黑名单 |
| 音准 | 只做整八度移位（不做半音自动校正，避免"跑调"） |
| 输出 | 16k 单声道 wav 15 秒（QQ 能播的格式） |
| 批量给人唱 | `node D:/AstrBot\sing_for.mjs --to <QQ> --song "告白气球,小幸运"`，唱不成自动换下一首并直接发过去 |

## 五、点歌（放原曲）🎵

- 「点歌 <歌名>」→ 网易云搜索 → 320k 直链（带会员 cookie）→ 切 40 秒副歌 → 发语音
- **配额**：每人每天 8 首、全局 40 首（防刷屏）
- 会员曲：cookie 有效时可下 320k；没版权/需购专辑的（如周杰伦原版）自动换翻唱版并注明
- 失败会区分原因：接口抽风（自动重试 3 次）/ 只有试听片段（换候选）/ 真的没版权
